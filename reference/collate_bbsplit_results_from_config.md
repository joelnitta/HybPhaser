# Collate BBSplit Results Using a HybPhaser Config File

Reads required settings from `config.txt` and runs
[`collate_bbsplit_results()`](https://joelnitta.github.io/rhybphaser/reference/collate_bbsplit_results.md).

## Usage

``` r
collate_bbsplit_results_from_config(config_file = "./config.txt")
```

## Arguments

- config_file:

  Path to HybPhaser configuration file.

## Value

Invisibly returns the same object as
[`collate_bbsplit_results()`](https://joelnitta.github.io/rhybphaser/reference/collate_bbsplit_results.md).
