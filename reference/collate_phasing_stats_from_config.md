# Collate Phasing BBSplit Stats Using a HybPhaser Config File

Reads required settings from `config.txt` and runs
[`collate_phasing_stats()`](https://joelnitta.github.io/rhybphaser/reference/collate_phasing_stats.md).

## Usage

``` r
collate_phasing_stats_from_config(config_file = "./config.txt")
```

## Arguments

- config_file:

  Path to HybPhaser configuration file.

## Value

Invisibly returns the same object as
[`collate_phasing_stats()`](https://joelnitta.github.io/rhybphaser/reference/collate_phasing_stats.md).
