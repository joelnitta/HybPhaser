# Check if HybPiper is Available in a Conda Environment

Verifies that `hybpiper` can be executed from the specified conda
environment.

## Usage

``` r
check_hybpiper_conda(env_name = "hybpiper_env", quiet = FALSE)
```

## Arguments

- env_name:

  Character; conda environment name

- quiet:

  Logical; if TRUE, suppresses messages

## Value

Logical; TRUE if HybPiper is available in the environment
