# Merge Sequence Lists Using a HybPhaser Config File

Reads required settings from `config.txt` and runs
[`merge_sequence_lists()`](https://joelnitta.github.io/rhybphaser/reference/merge_sequence_lists.md).

## Usage

``` r
merge_sequence_lists_from_config(config_file = "./config.txt")
```

## Arguments

- config_file:

  Path to HybPhaser configuration file.

## Value

Invisibly returns the same object as
[`merge_sequence_lists()`](https://joelnitta.github.io/rhybphaser/reference/merge_sequence_lists.md).
